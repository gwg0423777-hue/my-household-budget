# 나의 가계부 v2

2단계 기능:
- 1단계 전체 기능 유지
- 대시보드
- 월별 수입/지출/잔액/남은 채무 요약
- 카테고리별 지출 막대 그래프
- 최근 거래
- 부채/채무 관리
- 금융기관 대출 / 개인 채무 / 기타 채무 구분
- 최초 원금 / 상환액 / 잔여 원금
- 상환 등록 시 잔여 원금 자동 차감
- 상환 등록과 동시에 '대출상환' 지출 거래 자동 생성
- PWA 설치 기반 추가
- 모바일 반응형

데이터는 현재 버전에서 브라우저 localStorage에 저장됩니다.
다음 단계에서 로그인/서버 DB를 붙이면 PC와 휴대폰 간 동기화가 가능합니다.
