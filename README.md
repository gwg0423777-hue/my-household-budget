# 나의 가계부 Phase 5 · V2 디자인 · Supabase 연결 완료

V2 디자인과 Phase 4 기능을 유지하면서 Phase 5 편의 기능과 PC/모바일 계정 동기화를 포함한 버전입니다.

## 이번 연결 완료 버전
- `household-budget` Supabase 프로젝트 URL / Publishable Key가 `cloud-config.js`에 이미 설정되어 있습니다.
- `household_budget_data` 테이블 생성 완료
- RLS 활성화 및 로그인 사용자 본인 데이터만 접근 가능한 정책 적용 완료
- Realtime 대상 테이블 등록 완료
- Supabase 보안 Advisor 점검 결과 현재 관련 경고 없음

## Phase 5 기능
- 거래 검색: 내용 / 카테고리 / 결제수단 / 날짜 문자열
- 전체 기간 보기
- 수입·지출 / 카테고리 / 결제수단 / 최소·최대 금액 필터
- 거래 직접 수정
- CSV 내보내기
- 채무 상환 거래 삭제 시 잔여 원금 자동 복구
- PC · 모바일 계정 동기화
- 다른 기기 변경사항 실시간 반영
- 로컬 사본도 함께 유지

## 기존 기능
- 대시보드 / 거래 / 부채 / 자동화 / 입력 대기 / 자산 / 순자산
- 고정금액 / 나중 입력 / 알림만 자동화
- 비밀번호 잠금 / 자동 잠금
- JSON 백업 / 복원
- PWA 설치

## 설치
GitHub 저장소 최상위(root)의 기존 파일을 이 ZIP의 파일로 교체하세요.
사이트 주소는 그대로 유지됩니다.

그 다음 가계부의 `설정 / 백업` → `PC · 모바일 계정 동기화`에서 본인 계정을 만든 뒤 로그인하면 됩니다.
상세 절차는 `SETUP_CLOUD.md`를 참고하세요.


## 계정 비밀번호 재설정
- 동기화 로그인 영역의 `비밀번호를 잊으셨나요?` 버튼으로 재설정 이메일을 보낼 수 있습니다.
- 이메일 링크를 누르면 가계부의 `설정 / 백업` 화면에 새 비밀번호 입력 영역이 표시됩니다.
- 새 비밀번호 저장 후 PC와 모바일에서 같은 새 비밀번호를 사용하세요.
- Supabase Authentication의 Site URL / Redirect URL에는 실제 GitHub Pages 주소가 등록되어 있어야 합니다.


## 완전 비공개 잠금 화면
- 가계부 잠금 비밀번호가 설정된 경우 앱을 열자마자 대시보드/거래/부채/자산 등 본문 전체가 숨겨집니다.
- 기존처럼 잠금창 뒤로 가계부 내용이 흐릿하게 비치지 않습니다.
- 올바른 비밀번호로 잠금 해제한 뒤에만 가계부 본문이 표시됩니다.
- 새로 비밀번호를 설정하면 즉시 잠금 화면으로 전환됩니다.


## 거래내역 정렬 보정
- 거래내역 화면의 오른쪽 패널이 살짝 밀리던 현상을 수정했습니다.
- 검색/필터 영역이 화면 폭을 강제로 넓히지 않도록 반응형으로 정리했습니다.
- PC와 모바일 모두 가계부 본문 폭 안에서 좌우 정렬되도록 보정했습니다.


## 거래내역 보기 공간 확대
- 거래내역 목록 패널의 폭과 높이를 넓혀 자동화 일정 화면처럼 더 여유롭게 보이도록 조정했습니다.
- 필터 영역을 더 촘촘하게 정리해서 목록이 보이는 세로 공간을 늘렸습니다.
- PC에서는 오른쪽 목록 패널이 더 크게 보이고, 모바일에서는 자연스럽게 한 칼럼으로 정리됩니다.


## 시안 그대로에 가깝게 맞춘 거래내역 버전
- 거래내역 페이지를 미리 보여준 시안처럼 상단 검색/필터 → 요약 카드 4개 → 좌측 표 / 우측 도넛그래프 + TOP 5 구조로 재구성했습니다.
- 거래 추가/수정 기능은 표 아래 카드에서 계속 사용 가능합니다.
- 그래프, 순위, CSV, 수정/삭제, 동기화, 잠금, 자동화, 자산/부채 기능은 유지됩니다.


## 최종 시안 보정
- 헤더의 집 아이콘, 거래내역의 계산서 아이콘, 날짜/인사말 칩을 추가했습니다.
- 지출 TOP / 수입 TOP 탭을 모두 활성화했고, 데이터가 없으면 문구 대신 빈 순위 칸으로 유지되게 바꿨습니다.
- 카테고리 태그에 작은 아이콘을 함께 표시합니다.


## 상자 분리 디자인
- `나의 가계부` 브랜드 상자와 현재 페이지(대시보드/거래내역/부채/자동화/자산/설정) 제목 상자를 완전히 분리했습니다.
- 메뉴를 바꾸면 오른쪽 제목 상자의 아이콘·제목·설명이 함께 바뀝니다.
- 다른 페이지도 같은 카드형 디자인 언어로 통일했습니다.


## 추가 보정
- 거래내역 필터를 데스크톱에서 한 줄로 보이도록 조정했습니다.
- 자산 화면과 대시보드 자산 요약에서 `부채 보기 / 부채 숨기기` 버튼으로 부채 포함 여부를 토글할 수 있습니다. 숨김 상태에서는 순자산 계산에서 부채가 제외됩니다.
