# 나의 가계부 Phase 5 · V2 디자인 · Supabase 연결 완료

V2 디자인과 Phase 4 기능을 유지하면서 Phase 5 편의 기능과 PC/모바일 계정 동기화를 포함한 버전입니다.

## 이번 연결 완료 버전
- `household-budget` Supabase 프로젝트 URL / Publishable Key가 `cloud-config.js`에 이미 설정되어 있습니다.
- `household_budget_data` 테이블 생성 완료
- RLS 활성화 및 로그인 사용자 본인 데이터만 접근 가능한 정책 적용 완료
- Realtime 대상 테이블 등록 완료
- Supabase 보안 Advisor 점검 결과 현재 관련 경고 없음

## Phase 5 기능
- 거래 검색: 내용 / 카테고리 / 결제수단 / 날짜 문자열
- 전체 기간 보기
- 수입·지출 / 카테고리 / 결제수단 / 최소·최대 금액 필터
- 거래 직접 수정
- CSV 내보내기
- 채무 상환 거래 삭제 시 잔여 원금 자동 복구
- PC · 모바일 계정 동기화
- 다른 기기 변경사항 실시간 반영
- 로컬 사본도 함께 유지

## 기존 기능
- 대시보드 / 거래 / 부채 / 자동화 / 입력 대기 / 자산 / 순자산
- 고정금액 / 나중 입력 / 알림만 자동화
- 비밀번호 잠금 / 자동 잠금
- JSON 백업 / 복원
- PWA 설치

## 설치
GitHub 저장소 최상위(root)의 기존 파일을 이 ZIP의 파일로 교체하세요.
사이트 주소는 그대로 유지됩니다.

그 다음 가계부의 `설정 / 백업` → `PC · 모바일 계정 동기화`에서 본인 계정을 만든 뒤 로그인하면 됩니다.
상세 절차는 `SETUP_CLOUD.md`를 참고하세요.
